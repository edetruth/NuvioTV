# Matchday Timeline Implementation Plan (TL1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (one task, implemented inline).

**Goal:** The Matchday timeline (#24): the same games as Live Now and Upcoming as blocks on a local-time ruler, one row per league, a red now line, and the focused block's panel at the bottom (muted preview, big scoreline, linescore, situation line, Watch / Watch with another game / Game stats).

**Issue:** #24. **Design:** `docs/superpowers/designs/2026-11-16-sports-live-views/README.md` §1 Timeline, "Spoilers, delay and keys", "Built components", "Decisions" (3: Timeline is a layout switch); `Main.dc.html`.
**Builds on:** Scoreboard SB1/SB2 (`SportsLiveLayout`, `scoreboardRows`, `scoreboardButtons`, `scoreboardStartsIn`, the pane), #60 (`SportsLiveEndedGames`, `SportsLiveGameLength`), S5 (`SportsLiveScoreDetails`), SB1 (`GameSituations`), the card menu and pick mode in `SportsLiveScreen.kt`.

## Global constraints
- Spoilers and delay exactly as the Scoreboard: every block is built from a `ScoreboardRow` (`scoreboardRows`, same chip, group, art, follow and ended rules, same delayed snapshot); no new request. A live game is never hidden: its block always shows (red), only its score reads "Score hidden" under Hide until focused.
- No per-frame recomposition: block x offsets and the window scroll are read in the layout phase (`Modifier.offset { }`); the model is rebuilt only on the view model's clock tick (`SportsLiveUiState.nowMs`) or a scores/setting/reveal change.
- Strings only in `values/strings.xml`; sports-scoped code; shared files (strings.xml, SportsLiveScreen.kt) staged by hunk.
- Builds: one Gradle task at a time, `./gradlew --stop` around each, ≥ 6 GB free, no other java.

## Task TL1
1. **Layout switch.** `SportsLiveLayout.TIMELINE` (Cards · Scoreboard · Timeline) on Live Now and Upcoming; stored per tab per profile (`sports_live_layouts`, decode already tolerates it).
2. **Model** (`SportsLiveTimeline.kt`, pure, `@Immutable`):
   - `TimelineBlock(row: ScoreboardRow, kind LIVE/UPCOMING/FINAL, startMs, endMs, lane, startsIn)`; `TimelineLeague(name, followed, lanes, blocks)`; `TimelineModel(leagues, untimed, startMs, endMs, viewStartMs, viewMs, ticks, nowMs)`.
   - Start: ESPN's timed start, else the card's start with a time of day (the Scoreboard's `timedStart`). No time of day (channels, date-only): not on the ruler.
   - Length: `SportsLiveGameLength.of(item)` without its late-start buffer; a sport with no length (long sessions) uses the unknown-sport length. Live blocks end at max(now, start + length). Finals end where ESPN's final was first seen (`EndedGame.endedAtMs`), else min(now, start + length); an estimate ends at start + length. At least 15 min wide.
   - Kind: chip Final or group FINAL → FINAL (dimmed); group LIVE → LIVE; else UPCOMING.
   - Lanes: per league, greedy by start (first lane whose last block has ended).
   - League rows: followed rows first, then rows with a live block, then earliest start, then name.
3. **Window:** Live Now opens on now − 1 h … now + 5 h (6 h wide); Upcoming on now … now + 12 h (12 h wide). The ruler spans every block (floored/ceiled to local hours), so ← → scroll further. Ticks are local hour boundaries walked on the instant timeline (DST: a repeated or skipped hour shows as such, positions stay linear); a local midnight tick carries the day.
4. **No-time games:** a compact **"No time"** row after the league rows (chips in list order, not on the ruler), reachable with ↓, so channels and date-only games stay playable from the Timeline.
5. **UI** (`SportsLiveTimelineView.kt`): ruler with hour labels and the now tag; a LazyColumn of league rows (110 dp label column = 220 px at 1080p; blocks absolutely offset); a red now line overlay; block content (Live: red tint, "LIVE · clock", big score or "Score hidden"; Upcoming: outline, "6:00 PM · in 1 h 44 m", countdown only with a time of day; Final: dimmed, "FT 2–1" / "Final" / "Score hidden" / "Probably ended"); block text sticks to the window's left edge; the bottom panel (muted preview after the 2 s rest, LIVE tag, big scoreline + clock, S5 linescore/scorers, SB1 situation line, buttons shared with the Scoreboard pane).
6. **Remote:** a pure `timelineMoveTarget(model, key, move)`: ← → previous/next block of the row in time; ↑ ↓ the adjacent row's block nearest in time (overlap first); the no-time row by order. ↑ from the first row → filters/tabs; ↓ from the last row → Watch; ↑/← from the buttons → the block. OK = the card's OK (an ESPN final opens its Game page); hold OK / Menu = the card menu; pick mode, follow refocus and focus restore are the list's. The window animates to keep the focused block's start in view.
7. **Tests:** placement and lanes, kinds and ends, window math (across midnight, DST fall-back and spring-forward), no countdown for date-only, spoiler states (Hidden live block still shown, Off shows none), layout preference includes Timeline, focus moves.
