**Issues:** #18 (Game page), #54 (follow from Results / Game page).
**Design:** `docs/superpowers/designs/2026-11-16-sports-live-views/README.md` §4 Results, §5 Game page, "Built components", "Decisions", "Spoilers, delay and keys"; `GamePage.dc.html`.
**Builds on:** scores S1–S6 and Results R1 (`core/sportslive/scores/`, `ui/screens/sportslive/`), ledgers `.superpowers/sdd/2026-11-17-scores-v1/` and `.superpowers/sdd/2026-11-17-results-v2/`.

## Decisions (user, 2026-11-17)
- Results has no right panel. OK on a Results row opens the Game page; the page carries Watch replay (strict replay match only), Game stats and Follow ‹Team A› / ‹Team B›. Rows keep the Replay pill.
- Scores = Off: the Game page keeps score and stats behind a Reveal, and makes no request until Reveal.

## Global Constraints
- Precision: the page opens for a live card only on a strict match (the score chip's match and one-way-round sides). Replay matching stays strict (`SportsResults.replaysByEvent`).
- Requests: one ESPN `summary?event=<id>` per opened game on the event's own feed path. Finals disk-cached per event (trimmed DTO, capped file count). Live games: in-memory copy at most 30 s old, refreshed every 30 s only while the page is visible. Scores = Off: nothing until Reveal. Never play ESPN video.
- Spoilers: Show = all; Hide until focused = score, records and every section behind Reveal (a game already revealed where it was opened opens revealed); Off = the same, and no request before Reveal. Score delay: a game live when opened shows each summary only once it is `delay` old (none until then; the header falls back to the already delayed scoreboard snapshot).
- Follow: the existing `FollowedTeam` list, now with optional ESPN id, abbreviation and league (old name-only follows keep working). Name = ESPN display name; sport = a label that routes to the event's feed ("Basketball", "College Basketball", "American Football", "College Football", "Hockey", "Baseball", "Soccer"), so My sports gains the sport (R1 rule). Card matching compares sports by ESPN sport family, so an ESPN "Basketball" follow stars an addon "NBA" card.
- Strings only in values/strings.xml; sports-scoped code only.
- Builds: `source /d/Nuvio/tools/env.sh`; ≥6 GB free, no java/qemu; one Gradle task at a time with `./gradlew --stop` around each.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` + `Claude-Session:` line.
